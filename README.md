## Featured Projects

### 🧠 Dementia Cognitive Risk Assessment

A cognitive risk assessment tool developed through a research practicum with UNC Wilmington's nursing department. Collaborated in a three-student team under faculty supervision to build a logistic regression pipeline using National Health and Aging Trends Study (NHATS) data. Following model development, I was individually commissioned by the nursing department to deploy the tool as an interactive Streamlit application, featuring color-coded risk visualization and a circular arc gauge.

**Technologies:** Python · scikit-learn · Streamlit · pandas · Databricks · Logistic Regression · NHATS

[🚀 Live Demo](https://uncw-cognitive-risk-assessment-app.streamlit.app/) · [📂 Repository](https://github.com/farhatjoyan/Cognitive-Risk-Assessment-App)

### 📝 App Review Rating Prediction System

Developed an end-to-end NLP pipeline to predict app store review ratings using TF-IDF feature extraction and LightGBM. Built as a team project for a Software Engineering for Data Science course. Compared feature representations and modeling approaches to explore their impact on predictive performance.

**Technologies:** Python · LightGBM · TF-IDF · Azure ML · scikit-learn · NLP

[🔗 Project Site](https://uncw-dsc592-spring2026.github.io/Group-A-Webpage/index.html)

### 🌍 Predicting Women's Literacy in Afghanistan

Built a machine learning study using UNICEF MICS survey data to predict women's literacy outcomes in Afghanistan. Addressed class imbalance and compared Random Forest and CatBoost models. Analyzed feature importance to investigate the relationship between educational factors and predicted literacy outcomes.

**Technologies:** Python · scikit-learn · CatBoost · pandas · Exploratory Data Analysis · UNICEF MICS

[📂 Repository](https://github.com/farhatjoyan/afghanistan-womens-literacy-prediction)

### 🚀 Space Explorer Agent

Built an interactive AI application that combines NASA's Astronomy Picture of the Day API with a multi-agent system to answer users' space-related questions. One agent extracts astronomical context from the image description, while another synthesizes that context into clear, informative responses.

**Technologies:** Python · Streamlit · CrewAI · LiteLLM · NASA APOD API

*The repository is currently private due to restrictions related to the infrastructure used by the project.*

Currently working on a data science practicum focused on understanding customer behavior in the logistics industry. Exploring customer value metrics, segmentation approaches, and predictive modeling to identify behavioral patterns and support data-driven business decisions.

**Technologies:** Python · Snowflake · Machine Learning · Customer Analytics
